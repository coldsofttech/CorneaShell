# Support

- **How do I...?** Start with the [README](README.md), the [examples](examples) (each has its own README) and the [troubleshooting guide](docs/troubleshooting.md).
- **Something is not working:** run `cornea doctor` to check your machine, then open an issue with the bug report form. Attach the log from `cornea open ... --log-level debug --log-file cornea.log`, with any secrets removed.
- **Ideas and feature requests:** open an issue with the feature request form.
- **Questions and discussion:** use [GitHub Discussions](https://github.com/coldsofttech/CorneaShell/discussions) if it is enabled, otherwise open an issue.
- **Security problems:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

Cornea Shell supports Windows 10 and 11 with the WebView2 runtime. Other platforms are not supported yet.
