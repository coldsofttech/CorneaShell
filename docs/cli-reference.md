# `cornea`

Host a web UI in a native window with a secured local server.

**Usage**:

```console
$ cornea [OPTIONS] COMMAND [ARGS]...
```

**Options**:

* `-V, --version`: Show the version and exit.
* `-v, --verbose`: Show extra detail.  [env var: CORNEA_VERBOSE]
* `-q, --quiet`: Only show errors.  [env var: CORNEA_QUIET]
* `--no-color`: Disable colored output.  [env var: CORNEA_NO_COLOR]
* `--help`: Show this message and exit.

**Commands**:

* `info`: Show version and environment details.

## `cornea info`

Show version and environment details.

**Usage**:

```console
$ cornea info [OPTIONS]
```

**Options**:

* `--json`: Output as JSON.
* `--help`: Show this message and exit.
